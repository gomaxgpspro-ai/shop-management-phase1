# Customer, Vendor & Employee Module

- Customer and Vendor pages support add/edit/delete, active/inactive status, search, opening due, and profile view.
- Employee page supports categories Driver, SR, Sales Executive, Manager, Accountant, Technician, Office Staff, Store Keeper, Delivery Staff, Other.
- Employee System Role options: Admin, User, Manager.
- Employee profile shows contact details, category/role, status, created/updated timestamps and activity log.
- Records and activity log currently use browser Local Storage. The activity log captures changes made in these three pages; other modules need to be wired to the same activity logging service for a complete cross-module audit trail.
